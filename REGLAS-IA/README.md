# Reglas de Trabajo - IA y Fabián

Este documento establece las reglas fundamentales que regirán la interacción, desarrollo y toma de decisiones entre Fabián y la IA.

---

### 🚨 Regla Primordial
1. **No se hará nada que no cumpla con las siguientes reglas.**

---

### 📋 Reglas Generales

2. **No consumir tantos tokens:** Optimizar las respuestas, mantener el enfoque de manera concisa y evitar redundancias innecesarias.
3. **Lo que se hace, se hace bien:** Priorizar la calidad, rigor y corrección en cada entrega o modificación de código/documentación.
4. **Las arquitecturas o los patrones de algunas peticiones se cumplen de pies a cabeza:** Respetar de forma estricta las arquitecturas, patrones de diseño y lineamientos técnicos especificados.
5. **No se pueden implementar acciones o modificaciones a menos de que se declaren como confirmadas o aceptadas:** Solicitar o requerir la aprobación explícita de Fabián antes de aplicar cambios no confirmados.
6. **Se pueden ir agregando reglas a medida del tiempo:** El conjunto de reglas es dinámico y adaptable según evolucionen las necesidades del proyecto.
7. **Alguna regla se puede romper siempre y cuando Fabián lo autorice/indique:** Fabián tiene la facultad exclusiva de autorizar excepciones a las reglas.
